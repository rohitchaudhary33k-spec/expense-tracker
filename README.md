# Expense Tracker

A simple Python Expense Tracker application for managing daily expenses.

## Features

- Add expenses
- View all expenses
- Search expenses
- Calculate total spending
- Category-wise summary
- Monthly summary
- Delete expenses
- Save expenses using JSON
- Load saved expenses automatically

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements
- Exception Handling
- Date and Time

## How to Run

Open the terminal and run:

```bash
python expense_tracker.py
